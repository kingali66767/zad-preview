Questions et réponses

Poser une question à Zad

Posez votre question avec vos propres mots pour rechercher une réponse vérifiée. Pour les questions en arabe nécessitant une recherche, Zad peut consulter le site officiel du cheikh Ibn Baz.

Posez une question générale sans noms, données personnelles, détails sur votre unité ni lieu d’affectation. Les mots-clés peuvent être envoyés au site d’Ibn Baz pour la recherche.

Des questions générales peuvent être transmises à OpenAI pour rechercher des sources. Évitez les noms et les données personnelles.
